## Projects

**[MedAI](https://github.com/Oleksii-Lasiichuk/MedAI)** — multi-agent medical AI platform &nbsp; 🏆 *Jury Choice Award, SoftServe Agent Force Hackathon*
<br>Claude orchestrator dispatches 5 specialist medical models (MedGemma, MedSigLIP, HeAR) in parallel, collects results through a judge agent, and generates explainable reports with GradCAM heatmaps. RAG-based patient timeline for longitudinal context. Full stack: FastAPI + Next.js, GPU inference on Modal, deployed to GCP Cloud Run.

`Python` `FastAPI` `Anthropic Claude` `RAG` `Next.js` `Docker` `GCP` `Modal`

**[Cancer Cellular Automata](https://github.com/MaxDzioban/Cancer-cellular-automata)** — tumor growth simulation
<br>Real-time cellular automaton modeling tumor proliferation, chemotherapy, and immunotherapy. Probability-driven state transitions based on published oncology research. Interactive GUI with live cell-count stats and AI-assisted cell generation from JSON configs.

`Python` `NumPy` `Matplotlib`

**[Trapezna Recommendations](https://github.com/dark-neonus/trapezna-recomendations)** — PageRank-based dish ranking
<br>PageRank-inspired algorithm that computes dish relevance scores from user session graphs. Node weighting, aggregation, session tracking, and Graphviz visualization for the university cafeteria.

`Python` `PageRank` `Graphviz`
